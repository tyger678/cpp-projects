A collection of my C++ learning projects.

## Projects

### 🎮 Battle2.cpp
A console-based battle system between a player and an enemy with health, damage, and replay mechanics.

A simple banking system with `User` and `Account` classes — deposit, withdraw, and balance check.

## How to Run

1. Download the `.cpp` and `.exe` files and place them in the same folder.
2. Run the `.exe` file directly.

Or compile the `.cpp` file using any C++ compiler (Visual Studio, Code::Blocks, etc.).
